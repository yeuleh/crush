# Product Overview

Crush is a terminal-based AI assistant designed specifically for software development. It provides an interactive chat interface that integrates with multiple LLM providers and development tools to help developers write, debug, and understand code directly from the terminal.

## Key Features

- **Multi-Model Support**: Works with OpenAI, Anthropic, Google Gemini, AWS Bedrock, Azure OpenAI, and custom providers
- **Session-Based**: Maintains multiple work sessions and contexts per project
- **LSP Integration**: Uses Language Server Protocols for enhanced code context and analysis
- **MCP Extensibility**: Supports Model Context Protocol servers for additional capabilities
- **Cross-Platform**: First-class support on macOS, Linux, Windows, and BSD systems
- **Flexible Configuration**: JSON-based configuration with environment variable support

## Target Users

Software developers who prefer terminal-based workflows and want AI assistance integrated into their development environment without leaving the command line.

## Core Value Proposition

Crush bridges the gap between AI assistance and terminal-based development workflows, providing contextual help while respecting developer preferences for command-line tools and maintaining full control over their development environment.
