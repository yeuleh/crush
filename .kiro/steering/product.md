# Crush 项目产品概览

## 项目概述

Crush 是一个强大的终端 AI 助手，专为软件开发者设计。它提供智能编程辅助功能，直接在终端中为开发者提供代码分析、LSP 集成和交互式聊天界面，帮助开发者在终端环境下编写、调试和理解代码。

**定位**：终端原生的 AI 编程助手，通过键盘驱动的交互方式，为开发者提供即时的智能编程支持。

## 核心功能特性

### 多模型支持
- **支持多种 LLM 提供商**：OpenAI、Anthropic、Google Gemini、Azure OpenAI、AWS Bedrock、Groq、OpenRouter 等
- **灵活模型切换**：支持会话中切换不同模型，保持上下文连续性
- **自定义提供商**：支持 OpenAI 兼容和 Anthropic 兼容的自定义 API 端点
- **本地模型集成**：支持 Ollama、LM Studio 等本地模型服务

### LSP 集成
- **原生 LSP 客户端**：内置 Language Server Protocol 客户端，支持多种编程语言
- **代码上下文感知**：利用 LSP 提供的代码信息增强 AI 回答的准确性
- **支持常见语言服务器**：gopls (Go)、typescript-language-server、nil (Nix) 等
- **实时代码分析**：提供语法检查、类型信息、代码补全等能力

### 会话管理
- **持久化会话**：所有对话会话自动保存，支持跨会话访问历史记录
- **会话切换**：在多个项目会话之间快速切换
- **会话统计**：记录 token 使用量、成本统计和消息数量
- **会话搜索**：支持按标题和内容搜索历史会话

### MCP 扩展性
- **Model Context Protocol 支持**：集成 MCP 服务器扩展功能
- **多种传输方式**：支持 stdio、HTTP 和 Server-Sent Events 三种传输模式
- **环境变量展开**：支持动态环境变量配置
- **工具权限控制**：细粒度的工具执行权限管理

### 文件与上下文管理
- **项目文件索引**：自动索引项目文件，提供上下文信息
- **智能文件过滤**：遵循 `.gitignore` 和自定义 `.crushignore` 规则
- **文件版本跟踪**：记录文件修改历史和版本信息
- **上下文路径配置**：支持自定义上下文文件路径

### TUI 交互界面
- **现代终端界面**：基于 Bubble Tea v2 构建的响应式 TUI
- **多面板布局**：聊天区、编辑器、侧边栏、文件浏览器等组件
- **键盘导航**：完整的键盘快捷键支持，无需鼠标操作
- **紧凑模式**：适应不同终端尺寸的自适应布局
- **语法高亮**：代码块的语法着色和美化显示

## 支持的平台与安装

### 构建要求
- **Go 版本**：Go 1.25.0 或更高版本
- **编译环境**：支持 CGO_ENABLED=0 的静态编译

### 目标平台
通过 goreleaser 构建支持以下平台：
- **操作系统**：Linux、macOS、Windows、FreeBSD、OpenBSD、NetBSD、Android
- **架构**：amd64、arm64、386、arm (ARMv7)

### 安装方式
- **源码构建**：`go install github.com/charmbracelet/crush@latest`
- **包管理器**：Homebrew (macOS/Linux)、Scoop (Windows)、NPM、AUR (Arch Linux)
- **二进制下载**：GitHub Releases 提供多平台预编译二进制文件

## 主要使用场景

### 开发者工具
- **代码解释**：解释复杂代码逻辑和算法实现
- **代码重构**：提供重构建议和最佳实践
- **错误诊断**：协助调试和错误分析
- **API 文档查询**：快速获取 API 使用说明

### 学习与探索
- **技术概念解释**：深入解释编程概念和设计模式
- **代码示例生成**：生成特定需求的代码示例
- **最佳实践指导**：提供行业标准和最佳实践建议

### 项目协作
- **代码审查辅助**：协助进行代码审查和质量检查
- **文档生成**：生成项目文档和注释
- **架构设计讨论**：讨论系统架构和设计决策

## 目标用户群体

- **专业开发者**：日常使用终端进行开发工作的程序员
- **DevOps 工程师**：需要在服务器环境中进行运维和开发工作的技术人员
- **系统管理员**：管理和维护服务器系统的专业人士
- **技术学习者**：希望通过 AI 助手提高编程技能的学习者
- **开源贡献者**：参与开源项目开发和维护的开发者

## 竞争优势

- **终端原生体验**：专为终端用户设计，无需离开命令行环境
- **深度代码理解**：通过 LSP 集成实现真正的代码语义理解
- **隐私和安全**：本地存储会话数据，可配置不同级别的数据保护
- **高度可定制**：丰富的配置选项和扩展机制
- **轻量高效**：单一二进制文件，启动迅速，资源占用少
